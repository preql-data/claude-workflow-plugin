## 15. What is not true

Things a reader might reasonably assume, which are false:

1. **"CI is green."** It has never been green in this arc — not at the tag, not at HEAD.
2. **"The tag is the best tree."** It is the worse of the two by every measure except one unexplained new failure.
3. **"shellcheck failing/passing is load-bearing."** It is **advisory** — the job never blocks.
4. **"L2 passing means components work."** At HEAD, every L2 spec **skips** on `BD_SHIM_ONLY=1`. L2 gives near-zero signal in CI.
5. **"The suite is green locally, so it works."** The two regressions that reached `main`-bound commits were **invisible on macOS** and only appeared on Linux. Eleven review rounds on macOS found neither.
6. **"Review artifacts on disk mean reviews are recorded."** They are different things. Ten rounds of `h2zz` produced no `REVIEW-ARTIFACT` records until QA caught it.
7. **"292 open tasks is the backlog."** `.beads/issues.jsonl` (442 rows, mtime **Aug 26**) does *not* match the live store and must not be read as ground truth.
8. **"The plugin has been used on real work."** No evidence found (§13).

## 19. Release or refine

**Recommendation: a short refinement pass, then release.**

**What releasing now exposes, and to whom.** Teammates install from `main` via the curl one-liner. They would receive: a tree whose CI has never been green; `.claude/test-cmd` narrowing their own Stop gate; a P0 (`kyj5`) that writes litter into their `docs/reviews/` on every L1 run; and a design-phase gate (`qnvo`, P0) that may be **uncompletable** once the orchestrator touches a file outside a unit set.

**What a refinement pass buys, ranked:**

1. **Fix `qnvo`** — a P0 in a headline v5 mechanism. If task-per-unit approve is uncompletable, the flagship feature is broken for its main path.
2. **Fix `kyj5`** — stops litter generation at source and clears §16's second item.
3. **Move the tag to HEAD and regenerate the manifest** — releases the better tree.
4. **Remove `.claude/test-cmd`** — one deletion; restores full gate coverage.
5. **Resolve or consciously accept `4c6r`** — reproducible, unexplained, and possibly a real regression being correctly reported.
6. **Run the §13 install reality check** — the single highest-value unknown, given v4.1's failure mode.

**What I would cut for less surface:** the Linear adapter (`DP17`, the only NOT-PROVEN row). Cutting it takes the ledger to 11/6/0/0 and meets the historical release standard.

**What I would not stake the release on:** that v5 works in a target project. Nothing in this audit demonstrates it.
